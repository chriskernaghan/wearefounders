IcyZip solves the small daily annoyance of getting a link, a code or a paragraph from your phone onto your laptop. Open it on one device, scan the QR with the other, and both browsers share a live text field: type or paste on either side and it appears on the other. When you need to move an actual file, that's available as a separate action once the pairing is live, one file at a time rather than folders or batches.

The pairing is designed around real interruptions rather than ideal conditions. There's mobile wake recovery for when a phone sleeps mid-transfer, a fresh-QR path when a pairing expires, and an in-page camera scanner so you don't need a separate QR app. The QR code and shared link contain no secret themselves, and text and file bytes are encrypted in the browser before the service relays them.

What's refreshing is how precisely it describes its own privacy position. Rather than claiming to be a no-upload or offline tool, the FAQ states that the server relays ciphertext but can still see connection metadata: timing, IP-derived country, browser class, message size, and file details like name, type and size. That's an accurate description of a relayed end-to-end encrypted transfer, and it's the sort of distinction most tools in this space blur. It's free, needs no registration to test, and the interface is available in eight languages.
