IconVectors is a native desktop editor built for the narrow job of producing production-ready SVG icons, rather than general vector illustration. You draw on a pixel-perfect grid, keep stroke widths constant as icons scale, and watch the Live Code Viewer render the same icon as SVG, minified SVG, SVG Symbol, XAML, WPF Geometry, VectorDrawable, SwiftUI, ReactTS, VueTS or C++ as you work, so the handoff from drawing to codebase is a copy rather than a conversion step.

The MCP integration is what sets it apart from anything else in this space. A local Model Context Protocol server exposes 155 tools against the running editor, so Codex, Claude, Cursor, VS Code Copilot, Gemini CLI, Kiro, Cline or GitHub Copilot CLI can inspect the open document, create or edit geometry, run cleanup analysis, apply gradients, render previews and export results. That means an agent works on the live drawing rather than manipulating detached SVG text and hoping the result opens, and there are setup guides for each client.

Version 2.00 added an Icon Explorer for browsing folders as thumbnails with batch rename and delete, plus batch processing that applies a palette, resizes, or changes strokes across many files in one validated pass. Alongside that sit the Analyze and Clean Up workflow for off-grid geometry and inconsistent strokes, an element library, auto gradients, and one-click dark, hover and disabled variants. It's from Axialis, who've been building icon software for years, and the licence is perpetual at $79 with a year of free updates, covering all three platforms after a 30-day trial.
