thirds.ai is for the job nobody enjoys, which is producing the same asset forty times with different text on it. You set up a brand kit once with your logo, colours and fonts, start from a designer-made template, and then generate every variation from there as an image or a PDF. Smart resize handles reformatting the same design for different placements.

There are four ways to get files out, and the range is the point. You can work in the web editor, run a CSV batch, wire it into Zapier, Make or n8n, or hit the REST API directly with a template ID and a data object. There's also an MCP server, so Claude, ChatGPT or Cursor can request a finished file as part of whatever else they're doing. That makes it genuinely useful as a rendering step inside an agent workflow rather than only a tool you sit in front of.

The free tier is 50 credits a month with no card, files kept for 30 days, and those credits work on the AI features too. Paid plans run from $29/month for 2,500 credits up to $199/month for 40,000, with per-file costs dropping as you go up and higher tiers getting queue priority. There's also a $1 seven-day Starter trial and standalone credit packs from $10 if you'd rather not carry a subscription.

It's upfront about the boundaries. There's no video or motion work, nothing for print and prepress, and anyone wanting a full manual design suite is in the wrong place. The fit is marketers, ops teams and agencies producing many on-brand versions of a thing that already exists.
