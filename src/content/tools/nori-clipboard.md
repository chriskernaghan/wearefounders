Nori is a native SwiftUI clipboard manager for macOS that keeps everything you copy, text, links, images, colours, code and files, searchable after the next ⌘C. Quick Paste opens over whatever app you're in with ⌘⇧V, so you search and paste without switching context, with full keyboard navigation and readable previews for each content type.

The feature worth the attention is Flow Replay. Rather than only retrieving individual clips, it saves an ordered sequence and keeps it available for future sessions, so recurring work like filling the same onboarding form, assembling a quote, or pasting a standard set of details becomes one saved flow instead of hunting through history each time. Collections and favourites cover the other recurring items.

Privacy is handled by keeping things local: history and search run on the device, no account or cloud service is required to start, and you can exclude sensitive content or pause capture entirely. Pricing is a 14-day full trial then a one-time Lifetime licence, currently €9.99 as a founders offer for the first 100 buyers, with no renewals. It needs macOS 15 or later, and the site is upfront that anyone wanting a minimal recent-clips list might be better served by something simpler. The app and site are localised in English, Italian, German, French and Japanese.
